THE CAMPUS BOOKSTORE 2.0

Included files:
- app.py
- requirements.txt

Run locally:
1. Install Python.
2. Open Terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Deployment:
Upload app.py and requirements.txt to the root of your GitHub repository.
Deploy the repository on Streamlit Community Cloud with app.py as the main file.

Pages: Home, Browse Books, Shopping Cart, Offers & Student Zone, Checkout, Wishlist, About Us.
Real book photos are intentionally not included yet; placeholder covers can be replaced later.
This is a demo store only. It does not take payments or save orders.
